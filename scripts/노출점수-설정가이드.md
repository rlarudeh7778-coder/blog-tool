# 📊 블로그 노출점수 — 측정 서버(프록시) 설정 가이드

노출점수는 **네이버 검색 API**로 측정합니다. 그런데 이 API는 보안(시크릿)·CORS 때문에
브라우저에서 직접 못 부릅니다. 그래서 **무료 Cloudflare Worker**를 중계 서버로 한 번만 만들면 됩니다. (5분)

> 이미 네이버 **Client ID / Client Secret** 은 발급받으셨다고 가정합니다.

## 1단계. Cloudflare 가입 (무료)
1. https://dash.cloudflare.com 접속 → 무료 회원가입/로그인
2. 왼쪽 메뉴 **Workers & Pages** → **Create application** → **Create Worker**
3. 이름 입력(예: `blogscore`) → **Deploy** (일단 기본 코드로 배포)

## 2단계. 코드 붙여넣기
1. 방금 만든 Worker → **Edit code**
2. 편집기 내용을 전부 지우고, 저장소의 **`scripts/naver-score-worker.js`** 내용을 그대로 붙여넣기
3. 오른쪽 위 **Deploy**

## 3단계. 네이버 키 등록 (Secret)
1. Worker 화면 → **Settings** → **Variables and Secrets** (또는 Variables)
2. **Add variable** 로 2개 추가하고 각각 **Encrypt**(Secret) 처리:
   | 이름(Variable name) | 값(Value) |
   |---|---|
   | `NAVER_ID` | 네이버 Client ID |
   | `NAVER_SECRET` | 네이버 Client Secret |
3. **Save / Deploy**

## 4단계. 주소 복사 → 툴에 등록
1. Worker 화면 상단의 주소 복사 (예: `https://blogscore.글계정.workers.dev`)
2. 블로그툴 → **📊 노출점수** 탭 → 아래 **「⚙ 측정 서버(프록시) 설정」** 열기
3. 그 주소를 붙여넣고 **주소 저장**

## 끝! 사용법
- **📊 노출점수** 탭에서 블로그 아이디(예: `rlarudeh7778`)를 넣고 **측정하기**
- 최근 글 8개가 각자의 키워드로 네이버 블로그 검색결과에서 **몇 위에 노출되는지** 측정해 0~100점으로 환산합니다.

## 점검(선택) — 브라우저로 직접 확인
주소 끝에 `?blogId=아이디`를 붙여 열어보면 JSON이 나옵니다:
```
https://blogscore.xxxx.workers.dev/?blogId=rlarudeh7778
```
`{"blogId":"...","score":NN,"details":[...]}` 가 나오면 정상입니다.

## 참고/한계
- 네이버 공식 "지수" API는 없습니다. 이 점수는 **블로그 검색 API의 노출 순위 기반 추정치(beta)** 로,
  실제 통합검색/VIEW 노출과는 차이가 있을 수 있습니다.
- 검색 API 무료 한도: 하루 25,000회 (1회 측정 = 글 8개 = 약 8회 호출 → 넉넉합니다).
- 보안: Client Secret은 Worker의 Secret에만 들어가고, 블로그툴/깃허브 코드에는 저장되지 않습니다.
