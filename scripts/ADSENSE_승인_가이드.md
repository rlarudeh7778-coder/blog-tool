# 구글 애드센스 승인 가이드 (mapletelecom.kr)

> 거절 사유: **"가치가 별로 없는 콘텐츠(저품질/광고목적 사이트)"**
> 목표: 승인을 1순위로 두고 사이트를 '진짜 정보 사이트'로 보이게 만들기.

## 1. 자동발행 쪽에서 이미 바꾼 것 (코드 반영 완료)

| 항목 | 이전 | 변경 | 이유 |
|---|---|---|---|
| 선불폰 상업글 | IT글 3편마다 1편 | **OFF (phone_every=0)** | 전화·오픈채팅 CTA가 '광고목적 사이트' 신호 → 승인 전까지 끔 |
| 발행량 | 하루 2편 | **하루 1편** (min 1000분) | 신규 사이트 대량 자동발행 = 스팸 신호 |
| 글 길이 | 2,000~2,500자 | **3,200~4,200자** | 짧은 글 = 저품질 판정 |
| 글 깊이 | 단계 나열 | **'왜'까지 설명 + 자주 하는 실수 + 구체 수치** | 독창성(E-E-A-T) 강화 |

→ 승인 후에는 `scripts/autopost_config.json`에서 `phone_every`를 4, `min_minutes_between_posts`를 360으로 되돌리면 선불폰 글이 다시 섞여 발행됩니다.

## 2. 사장님이 직접 해야 할 것 (가장 중요)

### ✅ 2-1. 필수 페이지 3개 만들기  ← **이게 없어서 거절됐을 가능성 큼**
워드프레스 관리자 → **페이지 → 새 페이지 추가**로 아래 3개를 만들고, 메뉴(푸터/하단)에 링크하세요. 아래 본문을 그대로 붙여넣으면 됩니다.

### ✅ 2-2. 글이 최소 15~20편 이상 쌓일 때까지 기다리기
하루 1편씩 발행되니 2~3주 정도. 글이 충분히 쌓이고 페이지가 갖춰진 뒤 검토 요청하는 게 승인률이 높습니다.

### ✅ 2-3. 그 다음에 '검토 요청'
애드센스 → 사이트 → mapletelecom.kr → **'문제를 수정했음을 확인합니다' 체크 → 검토 요청**.
(한 번 거절 후 바로 또 요청하면 같은 사유로 빨리 거절될 수 있으니, 위 1·2 다 갖춘 뒤에 요청.)
