🔑 Claude API 키 운영자 전용
console.anthropic.com 에서 발급. 키는 이 브라우저(localStorage)에만 저장되며 외부로 전송되지 않습니다(분석 시 Anthropic 서버로만 전송).
📧 이메일 자동 발송 EmailJS · 선택
emailjs.com 무료 가입 → 이메일 서비스 연결 → 템플릿 생성. 템플릿 변수에 {{to_email}} {{to_name}} {{subject}} {{message_html}} 를 넣고, 받는사람(To)을 {{to_email}} 로 설정하세요. 미설정 시에는 PDF/이미지로 수동 전달하면 됩니다.
🎚 분석 분량
분량이 길수록 더 깊지만 생성 시간·비용이 늘어납니다. 10개 PART를 순차 생성합니다(약 1~3분).
ℹ️ 안내
만세력(천간지지·오행·십성·대운)은 천문 계산으로 산출합니다. 절기·합삭 경계의 출생자는 시간대 보정에 따라 일부 달라질 수 있으니, 중요한 감정은 전문 만세력과 교차 확인을 권합니다.
