# 🔮 AI 사주명리 분석 (독립 사업체용)

생년월일시를 입력하면 **만세력(사주팔자·오행·십성·대운)** 을 천문 계산으로 산출하고,
Claude AI가 **고급 프리미엄 10 PART** 분석을 작성하는 운영자용 도구입니다.
결과는 PDF·이미지·텍스트로 저장해 고객에게 전달합니다.

이 폴더(`saju-site/`)는 **블로그 도구와 완전히 분리된 독립 사이트**입니다.
파일은 `index.html` 하나로 동작(모든 코드 인라인, 외부 의존은 CDN뿐)합니다.

---

## 1) 새 GitHub 저장소로 옮겨 독립 운영하기

1. GitHub에서 **새 저장소** 생성 (예: `saju-myeongri`)
2. 이 폴더 안의 파일을 새 저장소 루트에 올립니다:
   - `index.html`  ← 사주 앱 본체
   - `.nojekyll`   ← GitHub Pages가 파일을 그대로 서빙하게 함

```bash
# 예시
git clone https://github.com/<아이디>/saju-myeongri.git
cd saju-myeongri
cp /경로/blog-tool/saju-site/index.html .
cp /경로/blog-tool/saju-site/.nojekyll .
git add -A && git commit -m "AI 사주명리 분석 사이트" && git push
```

3. 저장소 **Settings → Pages → Source = main 브랜치 / 루트(/)** 로 배포
4. 기본 주소: `https://<아이디>.github.io/saju-myeongri/`

## 2) 독립 도메인 연결 (예: `saju.co.kr`)

1. 도메인 구입(가비아·후이즈·Cloudflare 등)
2. DNS 설정
   - 정점 도메인(`example.com`): A 레코드 4개 →
     `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   - www 서브도메인: CNAME → `<아이디>.github.io`
3. GitHub 저장소 **Settings → Pages → Custom domain** 에 도메인 입력 → 저장
4. **Enforce HTTPS** 체크 (인증서 자동 발급, 몇 분~수시간 소요)

> 저장소에 `CNAME` 파일(내용: `example.com`)이 자동 생성됩니다. 그대로 두세요.

## 운영 방법

1. **⚙️ 설정** 탭에서 Claude API 키 저장 (운영자 본인 브라우저에만 저장됨)
   - 키 발급: https://console.anthropic.com
   - 키 저장소는 블로그 도구와 분리됨(`saju_ak`) — 서로 간섭 없음
2. **📝 고객정보 입력** → **🀄 사주판 계산** → **🔮 프리미엄 분석 생성**
3. **📄 PDF / 🖼 이미지 / 📋 텍스트** 로 저장 → 카톡·메일로 전달

- 분석 비용은 운영자 API 키로 청구(1건 수백 원~, 모델·분량에 따라 변동)
- 고객은 키가 필요 없습니다. 공개 URL에 올려도 키 없으면 분석 생성 불가
- 결제는 카카오페이·토스 등 **외부 결제 링크**로 받은 뒤 분석을 생성·전달(반자동)

## 계산 정확도

- 사주팔자 4기둥: 24절기(태양황경)·일주(율리우스일) 천문 계산
- 양력/음력(윤달 포함) 자동 변환: 합삭(신월)·무중기 윤달 판정
- 오행 분포 / 십성(십신) / 대운(순행·역행·대운수) 산출
- 절기·합삭 경계 출생자는 시간대 보정에 따라 달라질 수 있어 전문 만세력 교차 확인 권장
