# 🚀 사주 사이트 → 별도 저장소로 분리하기 (ruf.co.kr 그대로 유지)

> **왜 분리하나요?**
> GitHub Pages는 **저장소 1개당 사이트 1개 + 커스텀 도메인 1개**만 지원합니다.
> 지금처럼 `blog-tool` 저장소에 블로그 도구와 사주 사이트가 같이 있으면,
> `ruf.co.kr`(사주)과 `github.io/blog-tool/`(블로그 도구)이 계속 충돌합니다.
> → 사주를 **새 저장소**로 옮기면 둘이 완전히 분리됩니다. **Cloudflare/DNS는 그대로 재사용**하므로 추가 설정이 거의 없습니다.

---

## 1단계 · 새 GitHub 저장소 만들기
1. https://github.com/new
2. Repository name: **`saju`** (원하는 이름 가능)
3. **Public** 선택 → **Create repository**

## 2단계 · 이 폴더(`saju-site/`)의 파일을 새 저장소에 올리기

아래 9개 파일을 **새 저장소 루트**에 그대로 올립니다(폴더째가 아니라 **파일들만**):

```
index.html      ← 고객용 신청 페이지
admin.html      ← 운영자 도구
favicon.svg
favicon-192.png
og-image.png
CNAME           ← 내용: ruf.co.kr (그대로)
.nojekyll
README.md
AUTOMATION.md
```

**터미널로 한다면:**
```bash
git clone https://github.com/rlarudeh7778-coder/saju.git
cd saju
# (blog-tool/saju-site 안의 9개 파일을 이 폴더로 복사)
cp /경로/blog-tool/saju-site/* .
cp /경로/blog-tool/saju-site/.nojekyll .
git add -A
git commit -m "AI 사주명리 사이트"
git push
```

> 💡 GitHub 웹에서 올린다면: 새 저장소 → **Add file → Upload files** 로 위 파일들을 드래그.
> `.nojekyll`은 점(.)으로 시작해 숨김 파일이라, 웹 업로드 시 안 보이면 **Add file → Create new file** 에서 파일명 `.nojekyll` 로 빈 파일을 만들면 됩니다.

## 3단계 · 새 저장소에서 Pages 켜기
1. 새 저장소 **Settings → Pages**
2. Source: **Deploy from a branch** → Branch: **main** / 폴더 **/(root)** → **Save**
3. 잠시 후 빌드 완료 → `https://rlarudeh7778-coder.github.io/saju/` 로 임시 접속됨

## 4단계 · 커스텀 도메인 연결 (ruf.co.kr)
1. 같은 **Settings → Pages → Custom domain** 칸에 **`ruf.co.kr`** 입력 → **Save**
   - (저장소에 CNAME 파일이 이미 있어 자동 인식됩니다)
2. **DNS는 이미 해둔 Cloudflare 설정 그대로** 쓰면 됩니다 — 재설정 불필요!
   (A 레코드 185.199.108~111.153 + 네임서버 amy/newt.ns.cloudflare.com 그대로)
3. 몇 분~몇 시간 뒤 **Enforce HTTPS** 체크박스 활성화 → ✅ 체크

## 5단계 · (중요) blog-tool 저장소에서 정리
- `blog-tool` 저장소 **Settings → Pages → Custom domain** 에 만약 `ruf.co.kr`이 남아 있으면 **비우고 Save** (지금은 CNAME을 지워서 이미 해제됨)
- 이제 `github.io/blog-tool/` = **블로그 도구**, `ruf.co.kr` = **사주 사이트**로 완전 분리 ✅
